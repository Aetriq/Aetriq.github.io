Intrastice v0.1

Ultra-Compact CoreXY 3D Printer

Read Documentation GitHub Source

Overview

The planned 2nd generation of my custom CoreXY 3D printer series. A RepRap-ified Makerbot Replicator Plus, designed to be one of the world's most space-efficient 220mm³ CoreXY 3D printers. A direct successor to the Chimera iXY.

Featuring a custom edge-ML vision system for real-time anomaly detection, fully enclosed (in final design), CPAP cooling, and much more. It uses the compact Micro4 and ADXL345 FLY by Mellow, the Orange Pi Zero 2W, and a multi-voltage power bus solution for adaptable fans.

EDGE-ML VISION

Real-time anomaly detection identifying nozzle blobs and layer shifts.

SPACE EFFICIENCY

Optimized kinematics footprint housing a full 220mm³ build volume.
